Wir werden Shared Memory in Kombi mit Semaphoren nutzen (erster Gedanke)
-> vorallem hinsichtlich Teilaufgabe c & d mit einer gemeinsamen Liste die auf konsistente Zugriffe und Synchronisation achten soll

(Semaphore sorgt dafür, dass nicht zwei Prozesse gleichzeitig auf einem Speicher rumschreiben = kaputt)
(Daten liegen auf dem Shared Memory)

Teil a: Server erstellt Shared Memory und Semaphore.
Teil b: Client verbindet sich mit dem Shared Memory und kann Anfragen hineinschreiben bzw. Antworten lesen.
Teil c: Im Shared Memory legen wir eine gemeinsame Liste an und schützen Änderungen mit der Semaphore.
Teil d: Wir entfernen gedanklich die feste Rollenverteilung Server/Client. Jeder Prozess kann lesen, schreiben, Anfragen senden und beantworten.

Teil a:
1. fangen an mit einfachem Server -> schreibt etwas und mit client gucken wir uns das an
Und dabei ist ein wichtiger Unterschied zu unseren damaligen Sockets: Der Server hat dem Client streng genommen gar nichts gesendet.

Er hat nur etwas in einen Speicherbereich geschrieben, auf den beide Prozesse zugreifen können.

2. schreiben mit client wiederum nach dem empfangen was auf den gemeinsamen Speicher und lesen das mit dem Server wieder (Spieß umdrehen)
Der Client „sendet“ also nicht wirklich etwas, sondern verändert einfach gemeinsamen Speicher.

Was passiert, wenn Server und Client gleichzeitig schreiben oder einer liest, während der andere gerade schreibt?
Das ist dann der Punkt, an dem wir Semaphoren brauchen.

#include <stdio.h>
#include <stdlib.h>
#include <sys/ipc.h>
#include <sys/shm.h>
#include <string.h>

int main()
{
    key_t key;
    int shmid;
    char *shared_memory;

    // 1. Schlüssel erzeugen
    key = ftok("server.c", 65);

    if (key == -1)
    {
        perror("ftok");
        return 1;
    }

    // 2. Shared Memory anlegen
    shmid = shmget(
        key,                // welches Shared Memory?
        1024,               // Größe in Byte
        0666 | IPC_CREAT    // 0666 - Zugriffsrechte & IPC_CREAT - Falls segment noch nicht existiert -> anlegen
    );  
    // ergibt Shared-Memory-ID als Rückgabewert

    if (shmid == -1)
    {
        perror("shmget");
        return 1;
    }

    // 3. Shared Memory an diesen Prozess anbinden
    shared_memory = (char *) shmat(shmid, NULL, 0);
    //shared_memory zeigt auf gemeinsamen Speicher -> kann bespielt werden wie ein Array

    if (shared_memory == (char *) -1)
    {
        perror("shmat");
        return 1;
    }

    // 4. Testdaten schreiben
    strcpy(shared_memory, "Hallo aus dem Server!");

    printf("Shared Memory angelegt.\n");
    printf("Inhalt: %s\n", shared_memory);

    // erstmal warten, damit wir es mit ipcs anschauen können
    getchar();

    // Zurückschuss lesen
    printf("Nachricht vom Client: %s\n", shared_memory);

    // 5. Vom Shared Memory lösen
    shmdt(shared_memory);

    // Shared Memory entfernen
    shmctl(shmid, IPC_RMID, NULL);

    return 0;
}

typedef struct {...} pdu_t;

pdu_t *shared_memory;

shmat(...)

        └── Der Zeiger bekommt die Adresse
            des gemeinsamen Speichers.
